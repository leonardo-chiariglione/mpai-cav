ALL THE APPS THAT RUN - double-click the one you want. Each one starts what it needs.

Thalia (the MAS launcher; you choose an App in its window):
  01  Desktop client      (starts the Service, then the window)
  02  Browser server      (first closes any Thalia server still running, then starts the Service and the browser host
                           in its own window, and opens the page)
  03  Stops the Service and the clients

  The Apps Thalia offers: Multimodal Conversation (MAD), Question Answering (AMQ), Translation (MAT),
  Affective Dialogue (MPD), Newspaper Reading (NPR), Access Registration (ACR), Access Control (MAC), About MPAI (a video).

Other programs:
  10  ASM Studio (starts its Controller and its Module too)          11  CAV        12/13  ABV server        14  MMM demo
  15  EAE server (a virtual room of real speech; open http://localhost:5190/ with headphones)
  16-19  the Apps of CAE-USC, with dialogs to pick the files: 16 EAE, 17 SRS, 18 EES, 19 ARP (results in Documents\MPAI USC)
  20-26  the standalone programs (ACR, MAC, MAD, MAT, MPD, AMQ, HCI)
  30  Store service       31  Store app       40  AIH-HSP demo (the first slice, narrated)

This folder is part of the software tree: the software is the folder above it. The address of the Service is in _settings.bat.
The first start of a program builds it, which takes a little longer.
