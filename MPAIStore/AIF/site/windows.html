The AIF for Windows

The AI Framework of a user of the MPAI Store: the Controller (in the MPAI-MAS Service) and the AIM host. It takes the L3s from a folder or from the Store, obtains the package of each AIM and the data each AIM declares, verifies them, and runs the Module.

Install it

  1. Install the .NET 10 runtime (x64) if your computer does not have it.
  2. Download AIF-V3.0-win-x64.zip (13.5 MB) and check it (below).
  3. Unzip it in any folder, with any name: spaces and accents are fine. The folder may be read-only: nothing is written there.
  4. Copy mas-server.store.example.json to mas-server.json and write the address of the MPAI Store in StoreUrl and the Apps you want in Apps.
  5. Start it: service\MasService.exe mas-server.json.

Check what you downloaded

The SHA-256 of the file is:

C8CF1DBC5630D190078B601603C07B4DB11FA8F1EEC1BA041D908526105DB5DE

In PowerShell, in the folder of the file:

Get-FileHash AIF-V3.0-win-x64.zip -Algorithm SHA256

The two must be the same. If they are not, do not use the file.

What it does the first time

  • It takes the L3s of the Apps you chose from the MPAI Store.
  • It fetches the package of each AIM from the address its L3 names, and asks the Store whether it is the one the Store approved. A package the Store does not approve is not loaded.
  • It obtains the models, voices and programs that each AIM declares, once, and checks their SHA-256. Models can be a gigabyte or more, so the first start needs an Internet connection and disk space.

Where it keeps what it obtains

  • Models, voices and programs: %LOCALAPPDATA%\MPAI\AIF\Access. Another place: the environment variable MPAI_ACCESS.
  • The packages of the AIMs: the folder named by PackageCache in the configuration.

The access program

The AIF is the environment in which AI Modules run. What a person opens to reach the world of MPAI Apps is a program that uses it: MPAI Home (a provisional name). It lists the Apps that the MPAI Store offers, asks before the first download and opens an App in a window that follows its workflow.

MPAI Home is not available yet. Until it is, you start the AIF as above and use the Apps through a client of the MPAI-MAS Service it runs, such as Thalia.
