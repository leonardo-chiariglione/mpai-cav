Technical Specification: AI Module Profiles (MPAI-PRF) specifies a standard way to signal a label – called AI Module Profile – that uniquely identifies the set of AIM Attributes – input data, output data and functionality – that characterises an AI Module instance.

MPAI-PRF has been developed by the Multimodal Conversation (MPAI-MMC) and Portable Avatar Format (MPAI-PAF) Development Committees. MPAI may issue new Versions of this Technical Specification or new Technical Specifications.
